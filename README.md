#  Layihənin Adı: Team-project

Bu layihə, müasir veb standartlarına uyğun olaraq **HTML5** və **CSS3** texnologiyaları ilə hazırlanmış bir komanda işidir. Layihənin əsas məqsədi real istifadəçi təcrübəsinə uyğun, funksional və estetik bir veb səhifə yaratmaqdır.

 Mənim Öhdəliklərim və Texniki Detallar

Bu layihədə mən iki kritik hissəyə cavabdehlik daşıyırdım:

### 1. Footer (Saytın Aşağı Hissəsi)
Footer hissəsini tam sıfırdan kodlaşdıraraq aşağıdakı funksionallıqları təmin etdim:
* **Struktur:** Semantik HTML elementlərindən istifadə edərək saytın alt hissəsini təşkil etdim.
* **Naviqasiya:** Faydalı linklər, xidmətlər və əlaqə məlumatlarının səliqəli yerləşdirilməsi.
* **Sosial Media:** İkonların inteqrasiyası və onlara hover (üzərinə gəldikdə rəng dəyişmə) effektlərinin verilməsi.
* **Düzən:** `Flexbox` metodu ilə elementlərin bir-birinə nəzərən düzgün yerləşməsini təmin etdim.

### 2. Media Queries & Responsivlik (Mobil Uyğunluq)
Saytın təkcə kompüterlərdə deyil, həm də mobil telefon və planşetlərdə mükəmməl görünməsi üçün `Media Queries` hissəsini hazırladım:
* **Adaptivlik:** Ekran ölçüsü kiçildikdə Footer və digər elementlərin sıradan çıxmaması üçün xüsusi CSS qaydaları yazdım.
* **Breakpoint-lər:** 768px (planşet) və 480px (mobil) üçün xüsusi görünüşlər təyin etdim.
* **Grid to Column:** Masaüstü versiyada yanaşı duran blokların mobil versiyada alt-alta düşməsini təmin edərək oxunaqlılığı artırdım.
